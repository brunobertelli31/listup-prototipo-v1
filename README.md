# ListUp — prototipo V1

Prototipo navigabile della V1 di ListUp (social per gestire, condividere e cercare liste).

- `index.html` — il prototipo compilato, un solo file. Su GitHub Pages si apre direttamente.
- `sorgente/v1-prototipo.src.html` — il sorgente; le foto stanno in `sorgente/photos.json` e vengono inserite al posto di `__PHOTOS__` in fase di build.

Il prototipo gira tutto nel browser, senza backend: i dati sono finti e si azzerano a ogni ricarica.
